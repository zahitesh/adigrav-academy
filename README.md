# AdiGrav — Practical AI Engineering

Cohort-based programs for engineers and future engineers who want to design, ship, and lead with AI — taught from inside Google and Microsoft.

Built with:
- **React 18** + **TypeScript**
- **Tailwind CSS v4** + `@tailwindcss/vite`
- **Vite 6**
- **React Router v6**
- **Lucide Icons**

## Features

- **Interactive Landing Page**: Hero section with radial glow, dynamic waitlist form with track selection, founder cards, and responsive sticky navbar.
- **Auto-Triggered Callback Modal**: Auto-triggers on scroll engagement with custom 3D neural network artwork, fixed dimensions, and inline validation.
- **Detailed Curriculum Pages**:
  - `/10x-ai-engineer`: 12 modules, 6 production labs, lab filter, expandable syllabus.
  - `/ai-engineering-bootcamp`: 11 modules, 6 guided labs, lab filter, expandable syllabus.
- **Authentication View**: `/login` with real-time validation, password toggle, and Google / GitHub OAuth demo flows.

## Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
